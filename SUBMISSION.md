## Étapes

1. Connecte-toi à freeCodeCamp avec **ton compte**.
2. Pour chacun des 5 projets :
   - ouvre la page de soumission ci-dessus ;
   - clique sur **« Solution Link »** (ou le champ de lien) ;
   - colle le lien Colab correspondant ;
   - clique sur **« I've completed this challenge »** / **Submit**.
3. Une fois les 5 projets validés, ouvre :
   - https://www.freecodecamp.org/settings#certification-settings
   - ou la page du curriculum Machine Learning with Python ;
   - clique sur **« Claim Certification »**.
4. Le certificat est alors généré à l'adresse :
   `https://www.freecodecamp.org/certification/<ton-pseudo>/machine-learning-with-python-v7`

## Remarques

- Si freeCodeCamp exige un lien Google Drive plutôt qu'un lien GitHub :
  ouvre le lien Colab, fais **Fichier → Enregistrer une copie dans Drive**,
  exécute **Tout exécuter**, puis partage le notebook
  (« Toute personne disposant du lien ») et soumets ce lien Drive.
- L'entraînement du classifieur chats/chiens prend quelques minutes sur Colab ;
  c'est normal. Les sorties déjà enregistrées prouvent le résultat (96 %).
- La certification legacy n'impose pas d'examen. La nouvelle certification
  « Python » (python-v9) est différente et, elle, impose un examen.
